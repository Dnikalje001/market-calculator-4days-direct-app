# Market Calculator

Offline-first mobile app for the eight configured markets.

Daily use: choose a market, enter or update values, and run a calculation.

One-time market setup: import the calculation-sequence file and the cell-order file. These remain stored on the device until they are intentionally replaced.

The calculation audit must always show the three references, values, total, direct last digit, fourth-day `+5` last digit, and Match / No Match / Skip result.
